# シグマ型 練習問題 パート1

> 🌐 **翻訳元:** [idris-community/idris2-tutorial/src/Tutorial/DPair/Exercises1.md](https://github.com/idris-community/idris2-tutorial/blob/main/src/Tutorial/DPair/Exercises1.md)  
> 🤖 **翻訳:** Gemini 3.8 Flash

1. `Data.List.filter` と同様に、ベクトルをフィルタリングする関数を宣言・実装してください。

2. `Data.List.mapMaybe` と同様に、ベクトルに対して部分関数（`Maybe` を返す関数）をマッピングする関数を宣言・実装してください。

3. `Data.List.dropWhile` と同様の関数をベクトル向けに宣言・実装してください。戻り値の型には `Data.DPair.Exists` を使用してください。

4. 練習問題 3 を繰り返しますが、今度は通常の依存ペア（`DPair`）を返すようにしてください。実装には練習問題 3 の関数を利用してください。
